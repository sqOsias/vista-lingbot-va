# VISTA–WAM 迁移整理与验证报告（2026-10-16）

## 总体结论

项目已整理为可独立上传 GitHub 的 3.7 MB 代码与最小证据包。新代码不再依赖旧项目的阶段目录或 `/root/wyc/code` 固定路径；第三方仓库、模型、assets 和完整数据均可通过固定版本脚本恢复，也可用环境变量指向共享存储。新目录已在原服务器完成真实端到端 smoke，证明代码、冻结权重、D435 三相机、动作生成、数值解码、RMBench 执行和真实历史回灌可以连通。

## 整理结果

- `src/vista_wam`：统一的 Python 包，按 `core/memory/perception/model/control/sim/evaluation` 分工；
- `data_processing`：固定第三方 commit、下载 `posttrain-robotwin`/可选 Qwen、下载 RMBench assets/可选完整数据；
- `environment` 和 `scripts`：双环境安装、模型服务、安装核验和 smoke 入口；

- `docs`：架构、结果口径和从空服务器开始的完整迁移步骤。

未迁移旧 FastWAM、纯 base、历史训练权重、全量逐帧 NPZ、阶段日志、重复媒体和服务缓存。旧项目仍是完整历史档案，新仓库的结果是审阅子集。
