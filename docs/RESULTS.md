# 随仓库保留的最小结果

`results/evidence` 只保留当前研究判断需要的结构化结果：

- `nine_task_evaluation.json`：早期九任务解析执行/记忆先导；不能归为 WAM 成功，也不能把调用预算和计划复用差异全部归因于记忆。
- `deployment_capability_*`：posttrain-robotwin 身份、相机和原生能力确认；后训练权重不是纯 base，原生放置阳性不等于 RMBench 目标控制通过。
- `target_selectivity_*`：20 个 S3 后缀，原目标 2/10、替代目标 2/10、同场景两目标均成功 0/10，20/20 最终最近前方垫；只有四种视觉布局，且完整任务由外部前缀开始，故只报告后缀。
- `interface_diagnostic_*`：固定 seed 100065 的单布局 8 个文字条件和条件性 4 个视觉框条件。它诊断条件通道，不构成新场景成功率或记忆收益。

`results/media` 保留真实策略执行视频与条件输入对照图。大 NPZ、逐帧图片、日志、服务缓存和重复运行不进入迁移仓库；历史原件仍保存在旧项目中。
